# 《12:30！雙城集結令》Claude 開發交接包

**版本**：GDD v1.0 / 2026-11-13  
**交付類型**：完整規格、範例設定、線框參考與事件海報。**這不是已完成、可遊玩的遊戲。**

## 最快使用方式
1. 解壓縮此 ZIP，將整個資料夾提供給 Claude（支援檔案的 Claude 專案或 Claude Code 工作目錄）。
2. 先貼上 `CLAUDE_主提示詞.md` 全文，要求 Claude 依序讀完 `docs/` 與 `config/`。
3. 請 Claude 在**新的 `game/` 目錄**開發完整 HTML5 遊戲，不要更動原本《全民抓法克》專案和記錄。
4. 先驗收雙城引導核心玩法，再加入技能、Boss、紀錄相簿和正式部署。
5. **真實活動照片尚未提供**：`assets/photos/` 只有說明文件。請收到授權的真實照片後才加入公開版本。

## 資料夾導覽
- `CLAUDE_主提示詞.md`：可直接複製貼給 Claude 的完整任務指令。
- `docs/01_遊戲設計總綱.md`：敘事、定位、玩法、完整流程。
- `docs/02_角色與事件.md`：六類角色、隨機事件、技能。
- `docs/03_關卡與數值.md`：雙城階段、Boss、計分、平衡。
- `docs/04_UI_UX與美術音效.md`：畫面、手機、動畫、音效、無障礙。
- `docs/05_照片結局與資料治理.md`：真實照片、授權、成功失敗相同相簿。
- `docs/06_技術架構與部署.md`：Phaser/Vite、模組、儲存、安全及 GitHub Pages。
- `docs/07_測試與驗收.md`：逐條可驗證 QA。
- `docs/08_開發階段與交付.md`：迭代順序及輸出格式。
- `docs/09_文案台詞庫.md`：首頁、人物、結局、免責說明。
- `config/game-balance.json`：可調的推薦初始數值，需靠試玩調校。
- `config/event-photos.example.json`：相簿資料格式（示意路徑，非真實照片）。
- `config/save-data.example.json`：本機紀錄結構範例。
- `wireframes/`：文字線框，不是設計完稿。
- `references/11-13_event_poster.jpeg`：使用者提供的原始活動海報，供**視覺與事件脈絡參考**。

## 核心不可更改要求
- 主題：2026/11/13 12:30 桃園、台中兩地的活動，遊戲化改編，遊戲內虛擬人數**不是真實出席統計**。
- 單局目標約 4–6 分鐘，手機直式優先，電腦也能操作。
- 全部關卡不論成敗都能進入結局；**Boss 贏或輸都展示相同的兩地真實照片**。
- 從首頁直接進入紀錄相簿，不得鎖定照片。
- 當照片未提供時僅顯示「照片整理中」，不以生成圖假冒現場影像。
- 獨立專案與 localStorage 命名空間，勿清除《全民抓法克》舊紀錄。
- 上線前須檢查照片使用授權、肖像與其他識別資訊。
