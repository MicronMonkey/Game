# 04｜UI/UX、畫面、動畫、音效與無障礙

## 核心畫面
1. 開場動畫（陰天廠房→台灣地圖兩光點→太陽升起；首次 5s 可跳過）。
2. 首頁（開始／教學／最高紀錄／真實紀錄／音效／免責）。
3. 首次教學 6 步（選人、指派、陽光、技能、雙城、Boss）。
4. 雙城遊戲 HUD；Boss；勝敗過場；相簿/分享。

## 排版
- 手機直式 375x667、390x844、393x852、430x932 優先：桃園上、台中下，狀態列上方、技能列下方，避開安全區。
- 桌面寬螢幕：桃園左、台中右；不要讓場景無限拉寬，合理最大畫布寬度。
- 可視面積小時保持可玩區，縮小裝飾但不縮小觸控目標。
- HUD：時間/倒數/總分/暫停、桃園進度、台中進度、陽光值、三技能/冷卻、Combo、突發事件提示。
- 手機每個關鍵觸控目標至少 44×44 CSS px，不靠 Hover；框選模式為獨立切換。

## 色彩
深黑 `#101216`、暗灰 `#242832`、金黃 `#FFD447`、橘金 `#FF9F1C`、警示紅 `#E83B3B`、白 `#F5F5F5`、藍灰 `#64748B`。Q 版 2–2.5 頭身角色與街機漫畫視覺。

## 反饋動畫
- 角色抵達：彈跳/+100；Combo：增強光暈與音階；技能：圈形擴散；雙城達標：金色跨城連線。
- Boss：移動弱點、光束衝擊粒子、暴擊、短暫合理震屏、HP 20% 鎖鏈階段；擊敗時金光碎裂慢動作。
- 失敗時黑箱保留但兩城光點仍亮，避免誇張挫敗。
- 相簿過場：降低動效/音量，轉為紀實視覺。

## 音訊
原創或有公開使用授權的 BGM：首頁輕快、集結逐漸緊張、Boss 電子搖滾、紀錄溫暖柔和。音效：點擊/抵達/Combo/技能/事件/倒數/Boss 登場/受傷/勝利/失敗。瀏覽器首次用戶互動後解鎖音訊；靜音狀態記憶，不自動播放未授權內容。

## 可及性與效能
- `prefers-reduced-motion` 與遊戲內減少動態選項；禁止大量閃爍。
- 技能不能只靠顏色辨識：搭配圖示與倒數數字。
- 所有重要對話有字幕，音效可關；對低效能手機可降低粒子數量。
- 分頁失焦、打開相簿燈箱、切換設定均暫停可暫停的遊戲計時。
- 不阻擋手機返回操作；iOS Safari 音效/安全區/縮放應實測。
- 避免黑色背景與深灰文字對比不足。
