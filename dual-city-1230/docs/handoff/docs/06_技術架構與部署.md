# 06｜工程架構、存檔、部署與安全

## 開發堆疊
Phaser 3 + JavaScript ES6 Modules + Vite + CSS3 + Web Audio API；靜態 GitHub Pages。不依賴伺服器可完成核心玩法與個人紀錄。README 必須提供 Node 版本、`npm install`、`npm run dev`、`npm run build`、`npm run preview`、部署指令。

## 模組界線
- GameState：目前難度、分數、兩地進度、Combo、能量與計時。
- Pathing/CharacterSystem：選取、多選、避障、抵達事件只觸發一次。
- EventsSystem：冷卻、每次事件生命週期、觸發權重。
- SkillSystem：能量消耗、CD、Buff 上限和暫停。
- BossSystem：弱點移動、DPS、暴擊、階段切換、勝敗判定。
- Storage：版本化 localStorage，避免污染舊遊戲。
- PhotoGallery：獨立 JSON 讀取、載入錯誤、燈箱、相簿操作。
- ShareCard：Canvas PNG 下載及 `navigator.share` 可用時分享。

## 狀態轉移
`BOOT → MENU → (TUTORIAL) → GATHERING → SYNC → BOSS → SUCCESS_TRANSITION/FAILURE_TRANSITION → GALLERY → MENU/REPLAY`。
此外 `MENU → GALLERY` 必須直接可用。各場景的 Enter/Exit 需清理事件監聽器、Tween、計時器，防止重玩累積。

## 持久化
使用 `dualCity1230.save.v1` 類的唯一 key；內容見 `config/save-data.example.json`。保留版本欄位與資料遷移函數。僅存每難度最高分、最佳時間、遊玩次數、Boss 成功次數、最長連擊、成就、音量、減少動畫選項及教學狀態。**不要讀/寫《全民抓法克》其他 localStorage key**。

## 相簿與 GitHub Pages
如果站點部署在 `https://<user>.github.io/<repo>/`，Vite `base` 必須是 `/<repo>/`；使用 repo root/自訂域名時可調整為 `/`。所有 `fetch`、照片路徑和 asset URL 必須以 `import.meta.env.BASE_URL` 為基準，避免在子路徑部署出現 404。禁止直接使用 `/assets/...` 絕對路徑而忽略 base。

## 分享成績
Canvas 使用本地授權字型與圖片；Web Share 僅在瀏覽器支援時呼叫；否則下載 PNG + 複製分享文字/連結。載入跨域圖片時處理 tainted canvas；最好成績卡只用同站資源。遊戲成績必須標示「遊戲分數」，避免誤認為實際活動人數。

## 效能、可靠性
近年手機目標 60 FPS，低階設備可降 30；使用物件池、限制畫面同時人物/粒子數、lazy-load 真實照片、切到背景時暫停、低耗能模式。不能依賴無權限服務或未安裝 API。

## 隱私/內容
不蒐集員工識別資訊、IP、姓名、聯絡方式或精確位置；不設需登入才能看的內容。此為遊戲化作品，關卡事件不能假冒新聞事實。請勿加入真實人物名譽攻擊或未經證實的指控。
