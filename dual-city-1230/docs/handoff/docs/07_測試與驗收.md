# 07｜QA 與驗收清單（Claude 必須實測）

## 可啟動與平台
- [ ] `npm install` 及 `npm run build` 成功，Console 無致命錯誤。
- [ ] iPhone Safari、Android Chrome、桌面 Chrome/Edge 可操作；375×667、390×844、393×852、430×932、桌面 1366×768 版面可用。
- [ ] GitHub Pages 的子路徑部署可載入場景、照片 JSON、音效與字型。
- [ ] 斷網後（資源首次已載）不致造成白屏；缺少圖片有備援畫面。

## 首頁/教學
- [ ] 首次開場有略過選項；再次遊玩不強制重播。
- [ ] 首頁所有按鈕都有真實可用功能。
- [ ] 首次教學完整引導，玩家可跳過，教學狀態能持久化。
- [ ] 首頁「11/13 真實紀錄」無條件直達相簿。

## 雙城核心
- [ ] 桃園與台中同時正常更新，無一邊停擺。
- [ ] 點擊角色再點集合點能正確尋路到達。
- [ ] 框選多人在手機和桌面可用，不會與捲動/拖曳衝突。
- [ ] 每個角色抵達最多結算一次；分數及進度無重複漏洞。
- [ ] 第一幕虛擬時鐘正確映射 12:00–12:30，難度變化也正確。
- [ ] 事件生成、解除、消失正常；不會無限堵住唯一道路。
- [ ] 技能能量不足/CD 不能施放；暫停時 Buff/CD/倒數停止。
- [ ] 兩城都達標/一城達標/零城達標三種結果皆可進 Boss。

## Boss
- [ ] 方向控制手機手指與滑鼠皆流暢。
- [ ] DPS、弱點暴擊、Boss HP、時間及階段符合設定值。
- [ ] Boss 0 HP 成功；時間 0 且 HP>0 失敗；邊界情況判定一致。
- [ ] 成功/失敗過場可播放並跳過，**兩者都進相同紀錄相簿**。

## 相簿（P0 最高優先）
- [ ] Boss 成功與失敗進入相簿時，桃園/台中照片、順序、文案都相同。
- [ ] 沒有真實照片時顯示「照片整理中」，不能出現偽造照片。
- [ ] 僅一城有照片、缺一張照片、JSON 404、破圖都不白屏。
- [ ] 手機左右滑動、桌面箭頭、點擊放大、鍵盤返回操作正常。
- [ ] 照片完整比例呈現，不裁掉人物；可新增照片只改 JSON 和檔案。
- [ ] 相簿不要求登入/先通關/先分享。

## 成績與聲音
- [ ] localStorage 分難度保存最高分與成就，重載不消失。
- [ ] 重新遊玩能完整清理舊事件與物件；不會殘留舊局分數。
- [ ] 分享 PNG 正確輸出，Web Share 不支援時有回退。
- [ ] 音效預設符合瀏覽器手勢要求；靜音與減少動畫設定保留。
